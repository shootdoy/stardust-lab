# 편집 스킬 — 스타더스트 랩 `index.html`

이 파일을 고치다 **네 번 사고가 났다.** 넷 다 «계획» 이 아니라 «편집» 에서 났고,
넷 다 `dev/check.js` 로는 **사전에** 막을 수 없는 종류였다.

| 사고 | 원인 | 막는 단계 |
|---|---|---|
| 렌더 헬퍼 7개 유실 | 교체 범위에 남의 정의가 끼어 있었다 | **2** 사라질 정의 |
| `scrollToReadout` 유실 | 참조가 남은 채 정의를 지웠다 | **3** 참조 세기 |
| v3.48.1 스페셜 블록 3중 복제 | 앵커가 세 곳에 있었다 | **1** 앵커 유일성 |
| v1.42~1.46 통째 유실 | 스크립트가 죽어 **조용히 미저장** | **5** 되읽기 |

훅(`.claude/settings.json`)은 편집 **뒤에** `check.js` 를 돌린다 — 문법과 동작은 보지만
«무엇이 함께 사라졌는지» 도 «반영이 됐는지» 도 못 본다.
CLAUDE.md 의 «검증 통과 = 반영 완료가 아니다» 가 이 이야기다.

## 언제 트리거되나

- 사용자가 `/edit` 을 입력했을 때
- `index.html` 의 **함수·블록을 교체하거나 지울 때** — 스킬을 부르지 않아도 이 절차를 따른다

**규모에 맞춰 줄인다.** 숫자 하나·문구 하나 바꾸는 편집에 일곱 단계는 과하다 —
**1**(앵커 유일성)과 **5**(되읽기)만 하고 넘어간다. 큰 구간을 옮기거나 함수를 갈아 끼울 때만 전부 한다.

## 워크플로우

### 1. 앵커 유일성 — `grep -c` 가 아니라 `grep -o`

⚠⚠ **`grep -c` 를 쓰지 말 것. 그것은 «줄 수» 를 센다.** `index.html` 은 한 줄이 최대
**26,857자**라 한 줄에 여러 번 나오면 적게 센다. 실측 — `hEditIdx` 는 `grep -c` **25** 인데
실제 출현은 **27** 이다.

```bash
grep -o -- '<앵커>' release/index.html | wc -l
```

| 결과 | 할 일 |
|---|---|
| 0 | 앵커가 틀렸다. 파일을 다시 본다 (이미 고쳐져 있을 수도 있다) |
| 1 | 진행 |
| **2 이상** | **멈춘다.** 앞뒤를 붙여 앵커를 늘리고 다시 센다 |

v3.48.1 사고가 이 단계를 빼먹어 났다. `if(hEditIdx!=null){` 은 **지금도 세 곳에 있다** —
저장 핸들러 · 모드 전환 핸들러 · 목록 삭제 핸들러. 세 곳에 있는 것 자체는 정상이고,
**앵커로 쓸 수 없을 뿐**이다.

### 2. 사라질 구간의 «최상위 정의» 를 먼저 뽑는다

큰 구간을 바꿀 때만. 시작 앵커와 **끝 앵커(보통 다음 정의의 시작)** 사이에 무엇이 있는지 센다.

```bash
python3 - <<'EOF'
import io,re
s=io.open('release/index.html',encoding='utf-8').read()
A='function buildSeq'       # 교체 시작
B='/* ══ 렌더 ══ */'        # 교체 끝 — 보통 «다음 정의의 시작»
i=s.index(A); j=s.index(B,i); seg=s[i:j]
top=re.findall(r'^(?:function|const|let|var|class)\s+([A-Za-z_$][\w$]*)',seg,re.M)
print(f'구간 {len(seg)}자 · {seg.count(chr(10))+1}줄')
print(f'사라질 최상위 정의 {len(top)}개:', top)
EOF
```

`^` + `re.M` 이 핵심이다 — 이 파일의 최상위 정의는 줄머리(열 0)에서 시작하므로
함수 안의 지역 변수가 섞이지 않는다. (`re.M` 을 빼면 위 예가 **1개 → 32개**로 부푼다.)

**결과가 «바꾸려는 그것 하나» 가 아니면 멈춘다.** 첫 사고를 이 스크립트로 재현하면
`/* ══ 렌더 ══ */` ~ `function renderBosses` 구간에 **최상위 정의 31개**가 잡힌다 —
`el` `tp` `gm` `mc` `dc` `chip` `bossTag` 가 그 안에 있다. 그때 함께 사라진 일곱이다.

### 3. 참조를 먼저 센다 (정의를 지울 때만)

정의 1 + 호출 n 이면 **호출 쪽도 함께** 고친다. 정의만 지우면 문법 검사는 통과하고
실행해야 터진다 — `scrollToReadout` 사고가 그것이다.

```bash
grep -o -- '<지울 이름>' release/index.html | wc -l
```

### 4. 편집 — 정확한 문자열만

- `str_replace` 로 **정확한 문자열만** 바꾼다. 인덱스 슬라이싱(`s[a:b]`)으로 큰 구간을
  통째로 교체하지 않는다
- **한 번에 한 가지만** 바꾼다. 여러 곳을 동시에 바꾸면 무엇이 터졌는지 못 가른다
- ⚠ **`--write` 계열 스크립트를 `head` 로 파이프하지 말 것** (`artgen.py` 등).
  `head` 가 파이프를 닫으면 SIGPIPE 로 **저장 전에** 죽는데 화면에는 앞 몇 줄이 정상으로 찍힌다

### 5. 되읽어 확인 — 검증 통과 ≠ 반영 완료

```bash
grep -o -- '<새 문자열>' release/index.html | wc -l   # 기대 1
grep -o -- '<옛 문자열>' release/index.html | wc -l   # 기대 0
wc -c release/index.html                              # 크기가 예상만큼 변했는가
```

v1.42~1.46 유실이 이 단계를 빼먹어 났다 — 치환 스크립트가 예외로 죽어 파일이 저장되지
않았는데 문서만 앞서갔다. **검증 3종은 문법과 동작만 보므로 «변경이 안 들어간 것» 을 못 잡는다.**

아트를 넣었으면 키 수도 센다 (`sync.js` 의 `TAGIMG_N`·`LOW_N` 과 맞아야 통과한다):

```bash
python3 -c "import io,re;s=io.open('release/index.html',encoding='utf-8').read();
i=s.index('const TAGIMG={');j=s.index(chr(10)+'};',i);
print(len(re.findall(r'\"[^\"]+\":\"',s[i:j])))"
```

### 6. `dev/check.js`

훅이 자동으로 돌린다 — 단 **`index.html` 해시가 바뀔 때만** (`.claude/.idxhash`).
**결과는 눈으로 볼 것.** 훅을 껐거나 못 미더우면 손으로:

```bash
node dev/check.js          # undef · interact · fixture · glyph · sync (2.8초)
node dev/check.js --quick  # undef · interact 만 (최소 절차)
```

`undef.js` 의 **정상 오탐은 CSS 함수 이름 `var` `gradient` `rgba` 뿐**이다.
그 외 이름이 나오면 진짜 누락이다.

### 7. 기능이 바뀌었으면 두 가지를 더

**① `dev/sync.js` 에 검사 한 줄.** 안 넣으면 다음 편집에서 조용히 되돌아가도 아무도 모른다 —
v1.42~1.46 유실이 그렇게 났다. «있어야 하는 것» 과 «없어야 하는 옛 코드» 를 짝으로 두면
회귀까지 잡힌다 (예: `KHP=0.191` 있음 + `KHP=0.206` 없음).
⚠ **추가한 뒤 일부러 망가뜨려 잡히는지 확인할 것** — 통과만 하는 검사는 검사가 아니다.

**② 버전은 «세 곳» 이 아니라 «네 곳» 이다.** 어떤 값으로 올릴지는 잭이 정한다 —
**묻고 나서** 고친다.

```bash
grep -n 'name="version"\|const VERSION=\|const BUILT=' release/index.html
grep -n '^- 버전:' CLAUDE.md
```

| 고칠 곳 | |
|---|---|
| `<meta name="version">` | `index.html` 머리 |
| `const VERSION` | 스크립트 |
| `const BUILT` | **오늘 날짜** |
| **`- 버전: **vX.Y.Z** (날짜)`** | **`CLAUDE.md`** — `sync.js` 가 문서와 코드를 **대조한다** |

- ⚠⚠ **`CLAUDE.md` 를 빼먹으면 `sync` 가 «코드 안에서 버전이 어긋난다» 로 막는다.**
  2026-08-22 v3.48.2 에서 실제로 두 번 걸렸다 — `meta=3.48.1 상수=3.48.2 문서=3.48.1` 처럼
  **어디가 안 맞는지 훅이 찍어 주므로** 그 줄을 그대로 읽고 맞추면 된다
- ⚠ `grep` 에 네 번째로 잡히는 `t.match(/const VERSION='([^']+)'/)` 는 **`checkUpdate` 의 감지
  코드다. 건드리지 말 것**
- ⚠ 푸터 `<span class="ver">` 는 비워 둔다 — `VLABEL` 이 채운다. 값을 베껴 적으면 갈라진다
- `sync.js` 는 `BUILT` 가 «있는지» 만 본다. **날짜가 맞는지는 사람이 챙긴다**

**제목 문구를 새로 넣었으면** `node dev/glyph.js` 를 함께 돌린다 — 서브셋 폰트 373자 밖
글자를 잡는다. 서브셋에 **있어도 «틀» 은 자형이 뭉개져** 제목에 쓰지 않는다
(glyph.js 는 존재만 보고 자형은 못 본다).

## 금지 사항

| 금지 | 이유 |
|---|---|
| `grep -c` 로 앵커 세기 | 줄 수를 센다. 한 줄이 26,857자인 파일에서 적게 센다 |
| 유일하지 않은 앵커로 치환 | v3.48.1 3중 복제 — 없는 변수를 참조해 죽었다 |
| 인덱스 슬라이싱으로 큰 구간 교체 | 렌더 헬퍼 7개 유실이 이렇게 났다 |
| `--write` 를 `head` 로 파이프 | SIGPIPE 로 **조용히 미저장** |
| 편집 후 되읽기 생략 | 검증 통과 = 반영 완료가 아니다 |
| `alert`·`confirm`·`prompt` 추가 | 샌드박스에서 차단돼 조용히 무시된다. 인라인 확인으로 |
| 입력창 글자 16px 미만 | iOS 사파리가 확대하고 되돌리지 않는다 (세 번 재발) |
| `font:` 단축에 `inherit` | 선언 통째가 무효 · 조용히 16px. longhand 세 개로 쓴다 |
| 짧고 흔한 CSS 클래스명 신설 | 단일 HTML 이라 이름공간이 하나다 (`.lane` 사고) |
| `/* ══ 평가 ══ */`·`/* ══ 렌더 ══ */` 마커 삭제 | 검증 스크립트가 구간을 자르는 데 쓴다 |

## 자주 걸리는 함정

- **`Bag` 은 `Map` 이다** — `[...bag]` 은 `[id, 장수]` 쌍을 준다. 돌 때는 `bag.ids()`
- **base64 를 `url()` 에 직접 넣지 말 것** — `TAGIMG` 값은 원문이고, 아트는
  `artCls(c)` 가 주는 클래스의 `var(--art)` 로 쓴다 (DOM 중복 방지 설계)
- **모달은 뷰 밖 최상위에** 둔다 — 뷰 안에 두면 다른 탭에서 여는 순간 조용히 안 보인다
- **`.fl-m`·`.fl-n.wt` 규칙은 `.fl-tp` 보다 뒤에** — 특이도가 같아 순서가 이긴다
- **`save()` 에 항목을 더하면 `wipe()` 도 함께** 고친다 (기록 `HKEY` 는 예외 — 일부러 뺐다)
- **최상위에서 `addEventListener` 하는 id 는 `dev/interact.js` 스텁 목록에도** 넣는다 —
  목록에 없으면 `null` 이 와서 **스크립트가 통째로 죽는다**
- **공용 클래스 선택자를 id 로 되돌리지 말 것** (`.hposg`·`.hgotg`) — 플레이 화면 쪽이 조용히 죽는다
- **jsdom 한계와 jsdom 의 값** — `var(--art)` 가 `none` 으로 계산되는 것은 결함이 아니다.
  반대로 `getComputedStyle` 은 `font:` 무효를 **잡아 준다** — 마크업 구조만 보지 말고
  계산된 값을 확인할 것 (구조만 보고 세 번 놓쳤다)

## 편집 대상이 `index.html` 이 아닐 때

- **`docs/` · `CLAUDE.md`** — 위 절차가 필요 없다. 다만 코드와 어긋나는 서술을 새로 적으면
  `sync.js` 가 잡을 수 있으니 `node dev/sync.js` 를 한 번 돌린다
- **`dev/` 스크립트** — 훅은 `index.html` 만 본다. 고친 스크립트를 직접 돌려 확인한다
- **데이터를 더했으면** 에너지 검산부터 (`POOL` 1.00 · `SUBS` 2.50 이하 — **성급별로 기준이 다르다**)
- **규칙을 바꿨으면** `node dev/fixture.js` 로 위반 건수를 센다 (기믹 중복·탈진 위반 각 0건)
- **보스·데이터·규칙이 바뀌었으면** `best-a25.js`·`best-b25.js`·`best-c25.js` 를 다시 돌린다
  (각 10초). `check.js` 에 없는 것들이다
